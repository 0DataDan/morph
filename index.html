01 Instanced 3D DEM Terrain

All 10,000 terrain blocks render in a single WebGL draw call using InstancedMesh. Switching between Synthetic, Grand Canyon, Mt. Rainier, and Coastal Basin profiles morphs the heightfield in real time via flat typed arrays.

02 Min-Heap A* & Global Failover

Powered by an O(log N) binary MinHeap and pre-allocated typed arrays. Local strikes trigger a perimeter detour; if compound damage severs the network to 0%, a global TX→RX pass synthesizes a fresh valley corridor while discounting surviving traces:

cost = 1 + |Δz|·14 + max(0, z - 0.5)·1.8

03 Signal Rules & Drawing

Packets propagate using Wireworld cellular rules, cooling through a Decay state back into Corridor. Cursor strokes project onto the tilted Z = 0 plane via raycasting and fill gaps with Bresenham line interpolation.
